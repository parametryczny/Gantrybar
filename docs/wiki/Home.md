# Gantry Wiki — Polski / English

Gantry to lokalny monitor drukarek 3D z opcjonalnymi narzędziami farmy, magazynem filamentów i panelem na własnym hostingu.

Gantry is a local 3D-printer monitor with optional Farm tools, filament inventory and a dashboard on your own hosting.

Dokumentacja Gantry 0.14.0 dla macOS, Windows i Linux. Przewodniki opisują wspólny zakres funkcji; tryb LITE ogranicza aplikację do podglądu stanu.

Gantry 0.14.0 documentation for macOS, Windows and Linux. The guides describe a shared feature set; LITE mode limits the app to status monitoring.
