# Getting started with Gantry

[Polski](https://github.com/parametryczny/Gantrybar/wiki/Getting-started-PL) · [Contents](https://github.com/parametryczny/Gantrybar/wiki/Home)

Gantry shows printer status in the menu bar, system tray or fleet window. Local viewing requires no Gantry account.

## Add a printer

1. Launch the app and choose **Add printer…**.
2. Select the device type. Use discovery where available, or enter its address manually.
3. Enter the required access code, serial number, API key or password, depending on printer type.
4. Save and check the card. “Offline” means no current connection, not an empty queue.
5. Open Details to check temperatures, filament and camera availability.

Different printers expose different readings and commands. Status may work while firmware rejects control commands; Gantry displays these refusals.

## Choose a comfortable view

- **Settings → Appearance:** choose Gantry Basic or Gantry Modern, theme and card content.
- **Edit printer:** change the name or connection. Leaving the access-code field empty keeps the existing code.
- **Filaments / AMS:** check the active slot. Missing grams mean no available reading or spool assignment.
