# Pierwsze uruchomienie Gantry

[English](https://github.com/parametryczny/Gantrybar/wiki/Getting-started-EN) · [Spis treści](https://github.com/parametryczny/Gantrybar/wiki/Home)

Gantry pokazuje stan drukarek w pasku menu, zasobniku lub oknie floty. Do lokalnego podglądu nie potrzebujesz konta Gantry.

## Dodaj drukarkę

1. Uruchom aplikację i wybierz **Dodaj drukarkę…**.
2. Wybierz typ urządzenia. Użyj wykrywania, jeśli jest dostępne, albo wpisz adres ręcznie.
3. Podaj wymagany kod dostępu, numer seryjny, klucz API lub hasło — zależnie od typu drukarki.
4. Zapisz i sprawdź stan na karcie. „Offline” oznacza brak bieżącego połączenia, a nie pustą kolejkę.
5. Otwórz szczegóły, aby sprawdzić temperatury, filament i dostępność kamery.

Nie wszystkie drukarki udostępniają identyczne dane lub polecenia. Stan można odczytać, mimo że firmware odrzuca sterowanie. Gantry pokazuje takie odmowy w interfejsie.

## Ustaw wygodny widok

- **Ustawienia → Wygląd:** wybierz Gantry Basic albo Gantry Modern, motyw i zawartość kart.
- **Edytuj drukarkę:** zmień nazwę i połączenie. Puste pole kodu dostępu podczas edycji zachowuje istniejący kod.
- **Filamenty / AMS:** sprawdź aktywny slot. Brak gramów oznacza brak dostępnego odczytu lub przypisania rolki.
